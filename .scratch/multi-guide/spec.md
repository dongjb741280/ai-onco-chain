# Multi-guide 融合 spec

## Destination

把 `langgraph_diagnosis` 流水线从「单指南硬编码 CSCO」解耦为「多指南可插拔」：
先让 CACA 进线（`guide_caca.md` 已产出但未接），并为 NCCN / SITC / 中国医师协会 留接口。

## 核心认知：三层拆分

当前代码把三层混在一起，融合的关键是把「指南相关」的部分从「指南无关」的部分里剥离：

| 层 | 内容 | 指南相关？ |
|---|---|---|
| 临床事实 / 安全 | 分子分型、TNM 分期、安全红线 | 否（全指南通用，只判一次） |
| 决策链骨架 | A→U 诊疗路径（初诊→分期→新辅助/手术→辅助→复发→解救） | 否（临床路径的抽象，非某指南独有） |
| 推荐内容 | 某节点用何方案、何推荐等级、何证据类别 | **是**（唯一可插拔层） |

推论：**第 1、2 层保持唯一实现，只有第 3 层按指南注册。**

## 目标架构

```text
临床推理内核（唯一）: 分型 / 分期 / 红线 / A→U 骨架
        ↓ 需要「推荐证据」时
指南注册表（可插拔）: 每指南一个 GuidelineProfile
        ├─ sources: 指南 md + 章节解析
        ├─ grading: 原生等级词汇 → 规范等级（仅冲突检测用）
        └─ citation: 引用格式
        ↓
融合层: 多路检索（带指南身份） → 跨指南 diff → 冲突交人工
```

两个新抽象：

1. **GuidelineProfile**：`config.GUIDE_PATH` 由单个 `Path` 改为 `list[GuidelineProfile]`；
   `GuideRetriever` 对每个 profile 建索引，检索结果带 `guide` 身份字段，报告引用带指南名。
2. **规范等级归一化**：两个正交粗维度——推荐强度（强 / 条件 / 不足）+ 证据等级（高 / 中 / 低），
   **仅用于跨指南 diff 与冲突检测**；报告保留各指南原生等级 + 原始出处，不做「统一等级」硬套。

## 关键取舍（已拍）

两条路线：

- **A 检索融合（务实）**：A→U 骨架不动，指南作为带身份的推荐证据源挂到各节点，
  多路检索 + 逐条标源 + 冲突并列交人工。改动小、CACA 立刻可用；骨架仍 CSCO 中心。
- **B 统一决策模型（激进）**：定义独立于任何指南的规范决策图，全指南归一化进去。
  长期最干净，但等于发明临床本体（CSCO 决策表 / NCCN pathway 树 / CACA 叙述规范 无法 1:1 映射），大工程。

**决策：A 起步，B 留口。** Profile 里 `decision_chain` 字段先置 `None`，将来某指南真有自己的拓扑再填。

## 指南形态差异（设计约束）

不是所有指南都是「全路径」指南：

- **全路径**：CSCO（决策表 + Ⅰ/Ⅱ/Ⅲ + 1A/2B）、NCCN（pathway 树 + Category 1/2A/2B/3 + Preferred/Other/Useful）
- **规范 / 叙述**：CACA（按章节叙述，全身治疗 10.1–10.4，推荐强度散在）
- **主题型**：SITC（免疫治疗，另一条轴）、中国医师协会（待定主题）

推论：决策链骨架是唯一 backbone，**不假设每个指南都提供完整链**；主题型指南只填充部分节点。

## 落地顺序

1. `config` 改 `list[GuidelineProfile]`；`GuideRetriever` 多索引 + 结果带 `guide`；报告引用带指南名 → CACA 进线。→ issue 01
2. 报告加「跨指南对比」小节：同节点 CSCO vs CACA 并列 + 冲突高亮，默认不自动裁决。→ issue 02
3. 结构化决策层（hybrid-kb issue 03）泛化：加 `指南来源` + `规范等级`。→ issue 03
4. 冲突裁决策略抽可配置项（默认人工；可配 中国指南优先 / 最新优先）。→ issue 04

## 术语（待 /domain-modeling 落 CONTEXT.md）

- **指南来源 / 指南身份**：检索结果标注出自哪份指南的字段（新增）。
- **规范推荐强度 / 规范证据等级**：跨指南 diff 用的粗归一化维度（新增，仅冲突检测，不用于报告展示）。

## Out of scope

- 多癌种（仍仅 HER2+ 乳腺癌）。
- 自动裁决指南冲突（默认交人工，符合既有 HITL 设计）。
- 统一决策模型 B（只留接口，不在本轮实现）。
